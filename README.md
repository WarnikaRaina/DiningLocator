# Dining Locator

Dining Locator is a web application that enables users to find nearby restaurants offering a specific food item. By entering the name of a dish, users can discover establishments that serve it, along with essential details such as location, contact information, and ratings.

## Features

- **Search by Food Item**: Input the name of a food item to find restaurants that serve it.
- **Location-Based Results**: View restaurants near your current location or search in a specific area.
- **Restaurant Details**: Access information including restaurant names, addresses, and contact details.
- **Map Integration**: Visualize restaurant locations on an interactive map.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB (or any other preferred database)
- **APIs**: Google Places API for location and restaurant data

## Usage

1. Open the application in your browser.
2. Enter the name of a food item in the search bar.
3. Allow the app to access your location or enter a specific address.
4. Browse the list of restaurants offering the selected food item.
